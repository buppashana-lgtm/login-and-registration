# Flutter Login and Registration App

## Project Description

This project is a Flutter mobile application that demonstrates a Login and Registration interface. The application allows users to enter their login details, create a new account, navigate between Login and Registration pages, and validate basic form inputs.

## Features

* Login page
* Registration page
* Email/Username input
* Full Name input
* Password input
* Confirm Password input
* Show/Hide password functionality
* Basic form validation
* Forgot Password option
* Navigation between Login and Registration pages
* Clean and user-friendly interface

## How to Run the Project

1. Clone this repository.
2. Open the project in Android Studio or Visual Studio Code.
3. Run `flutter pub get` in the terminal.
4. Start an Android emulator or connect a physical device.
5. Run the application using `flutter run`.
